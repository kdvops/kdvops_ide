# Asistente Conversacional DevOps

## Paquete Spec Driven Development

Versión documentada: v0.5.0  
Versión objetivo: v0.5.0  
Fecha: 2026-11-07

Este paquete documenta la evolución v0.5.0 de un asistente conversacional DevOps basado en reglas, sin IA generativa. Incluye planificación determinista de solicitudes compuestas, estado global de respuesta, propagación de namespace y consultas de solo lectura.

## Contenido

- `requirements.md`: alcance, requisitos funcionales y no funcionales.
- `api-contracts.md`: contrato observado de la API y contrato propuesto para v0.5.0.
- `roadmap.md`: evolución por incrementos verificables.
- `traceability.md`: relación entre evidencia, requisitos, especificaciones y pruebas.
- `specifications/`: especificaciones funcionales con criterios de aceptación.
- `architecture/decisions/`: decisiones arquitectónicas registradas como ADR.

## Regla de estado

`Implementado` significa que aparece en la evidencia de la conversación anterior. `Propuesto` significa que requiere implementación y pruebas adicionales. Este paquete no convierte una propuesta en una afirmación de disponibilidad.
