# Asistente Conversacional DevOps

## Software Design Document

Versión documentada: v0.5.0  
Evolución propuesta: v0.5.0  
Fecha: 2026-11-07

Este documento describe la arquitectura implementada de un asistente conversacional DevOps basado en reglas, con una API HTTP `POST /api/chat`, planificación determinista de solicitudes compuestas, contexto acotado y una barrera de solo lectura.

## Documentos

- `system-design.md`: arquitectura lógica y límites.
- `components.md`: responsabilidades y contratos internos.
- `flows.md`: flujos de consulta, bloqueo y evolución v0.5.0.
- `security.md`: modelo de amenazas y controles.
- `deployment.md`: despliegue documentado sin inventar infraestructura no confirmada.
- `assumptions-and-status.md`: decisiones sobre evidencia y estado.
